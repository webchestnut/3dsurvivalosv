# 3dsurvival

**Версия 1.0** — 3D-игра на выживание от первого лица в браузере. Постапокалиптический город и лес, день и ночь, зомби, крафт и песочница. Всё в одном файле `index.html`, без установки и сборки.

## Играть

Открой `index.html` в браузере (нужен интернет: библиотека [Three.js r128](https://threejs.org) подгружается с CDN).
Лучше всего работает в Chrome, Safari и Firefox на компьютере.

## Управление

| Действие | Клавиши |
|---|---|
| Захват мыши | клик по экрану (Esc — выйти) |
| Движение | WASD, Shift — бег, Пробел — прыжок |
| Бить, открывать двери, обыскивать, рубить | клик / F / E |
| Фонарь | L |
| Костёр / баррикада | 1 / 2 |
| Съесть или выпить | 3 |
| Повязка | 4 |
| Копьё | 5 |
| Батарейка / аптечка | 6 / 7 |

## Что есть в игре

- Процедурный город (дороги, площадки, здания в 1–4 этажа с лестницами, дверями и окнами) и лес с лагерями. Мир каждый раз новый.
- Смена дня и ночи: 3 минуты день, 4 минуты ночь. Зомби появляются только ночью, на рассвете рассыпаются.
- Ночью хоррор-освещение: свой фонарик с зарядом и батарейками, мерцание, туман, звук сердцебиения.
- Выживание: здоровье, сытость, еда, вода, аптечки, крафт костров, баррикад и копья.
- Ящики разных размеров и цветов, машины и контейнеры. С каждым днём припасы появляются снова.
- Физика: двери открываются и закрываются, стекло разбивается, стены, лестницы и предметы непроходимы.
- Все текстуры рисуются кодом при запуске, внешних картинок нет.

## Публикация на GitHub Pages

1. Создай репозиторий `3dsurvival` на GitHub и загрузи все файлы из этой папки.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)` → Save.
3. Через минуту игра будет доступна по адресу `https://<твой-логин>.github.io/3dsurvival/`.

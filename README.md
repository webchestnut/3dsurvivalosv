# 3dsurvivalosv — сайт и версии игры

Сайт **3dsurvivalosv** со списком версий 3D-игры. У каждой версии есть кнопка «Играть», игра открывается в новой вкладке.

## Структура

```
index.html        — сайт (список версий, кнопка «Играть»)
versions.js       — список версий (редактируй этот файл)
games/v1.0/       — игра версии 1.0 (index.html)
LICENSE
```

## Как добавить новую версию

1. Создай папку `games/v1.1/` и положи туда файл игры `index.html`.
2. Открой `versions.js` и добавь новую запись **в начало** списка:

```js
{
  version: "1.1",
  date: "20 октября 2026",
  title: "Название обновления",
  path: "v1.1",
  changes: ["Что нового 1", "Что нового 2"]
},
```

Сайт сам покажет её как последнюю, а кнопка «Играть» на главной переключится на неё. Старые версии остаются в списке.

## Публикация на GitHub Pages

1. Загрузи все файлы в репозиторий `3dsurvivalosv`.
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Сайт будет по адресу `https://<твой-логин>.github.io/3dsurvivalosv/`.

Сайт можно открыть и локально двойным кликом по `index.html`.
